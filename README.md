# Daily Planner

## Overview

Daily Planner is a responsive web application that helps users organize their daily activities. It includes user authentication, task management, goal tracking, notes, a weekly planner, and a personal profile.

## Features

* User Registration
* User Login
* Password Reset
* Firebase Authentication
* Dashboard
* Daily Task Management
* Weekly Planner
* Goals
* Notes
* Progress Tracking
* Calendar
* Dark Mode
* User Profile
* Change Display Name
* Change Password
* Responsive Design

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6 Modules)
* Firebase Authentication
* Firebase Firestore
* Google Fonts (Poppins)
* Vercel

## Setup Instructions

1. Clone or download the project.
2. Create a Firebase project.
3. Enable **Authentication** (Email/Password).
4. Enable **Cloud Firestore**.
5. Replace the Firebase configuration in `js/firebase.js`.
6. Open the project using a local server (such as VS Code Live Server).
7. Register a new account and start using the application.
